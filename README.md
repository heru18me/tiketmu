# Tiketmu

Platform event management MVP (seperti loket.com). Organizer membuat dan mengelola event, customer membeli tiket dengan alur pembayaran, voucher, kupon, dan poin referral.

## Struktur

- `apps/backend` — Express + TypeScript + Prisma + PostgreSQL
- `apps/frontend` — Vite + React + TypeScript + Tailwind CSS
